====================================================================
Wi-Track Integration Guide & ESP32 Data Format Documentation
====================================================================

1. ESP32 CSI SERIAL DATA FORMAT EXPECTED
--------------------------------------------------------------------
Your ESP32 sends CSI packet lines over Serial (at 115200 baud) in the
following format:

  CSI_DATA,AP,3C:71:BF:6D:2A:78,-73,11,1,0,1,1,1,0,0,0,0,-93,0,1,1,80272146,0,101,0,0,80.36,128,[ I0 Q0 I1 Q1 I2 Q2 ... ]

What our backend `csi_parser.py` does:
- Isolates the bracketed `[ ... ]` array containing the raw I/Q pairs.
- Separates them into `i_values` (In-phase) and `q_values` (Quadrature).
- Calculates `amplitudes` = sqrt(I^2 + Q^2) for each subcarrier.
- Wraps them into a `CSIPacket` and streams JSON over WebSocket (`/ws/data`).


2. BACKEND MODULES CREATED
--------------------------------------------------------------------
The backend is now completely modular:
- `backend/config.py`: Environment variables & settings (`SERIAL_PORT`, `BAUD_RATE`, `USE_MOCK`).
- `backend/csi_parser.py`: Pure line parser for bracketed ESP32 CSI data.
- `backend/serial_reader.py`: Serial port reader & Mock CSV reader fallback.
- `backend/main.py`: Modular FastAPI server with WebSocket endpoint & model plugin slot.


3. FRONTEND MODEL ASSET & RESPONSIBILITY
--------------------------------------------------------------------
- Model file location: `dashboard/frontend/public/yolov8n.onnx` (12 MB binary).
- The `yolo.ts` engine and `useYOLO.ts` React hook are delegated to the
  frontend team as requested. They can load `/yolov8n.onnx` directly via
  `onnxruntime-web`.


4. HOW TO RUN THE BACKEND
--------------------------------------------------------------------
With real ESP32 serial data:
  cd dashboard/backend
  SERIAL_PORT=/dev/ttyUSB0 uvicorn main:app --port 8000 --reload

In Mock CSV test mode (without hardware):
  cd dashboard/backend
  USE_MOCK=true uvicorn main:app --port 8000 --reload
